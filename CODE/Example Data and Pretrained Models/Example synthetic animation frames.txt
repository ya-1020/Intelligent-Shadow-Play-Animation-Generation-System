# Example Synthetic Animation Frames

This directory provides **representative synthetic animation frames**
generated by the proposed conditional GAN model. These examples are
intended to demonstrate the **visual output format and animation
generation pipeline**, without releasing the full training dataset.

All frames are generated from **synthetic or example keypoint sequences**
using the publicly available inference code.

---

## Frame Format

Each animation frame is stored as an RGB image with the following properties:

- Resolution: 256 × 256 pixels
- Color space: RGB
- Value range: normalized to [0, 255] for visualization
- File format: PNG
